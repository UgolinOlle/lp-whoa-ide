## 📦 Plugins de code dans WhoaIDE

Le dossier `lua/plugins/code` regroupe tous les plugins liés à l’édition de code, l’autocomplétion, l’IA, le linting, le formatage, Git, et plus encore.  
Voici un résumé de chaque plugin et de son utilité.

---

### 🤖 IA & Autocomplétion

- **[yetone/avante.nvim](https://github.com/yetone/avante.nvim)**  
  Intègre des assistants IA (Copilot, Ollama, Claude, etc.) pour suggestions et chat de code.

- **[hrsh7th/nvim-cmp](https://github.com/hrsh7th/nvim-cmp)**  
  Moteur d’autocomplétion puissant pour Neovim.

  - **[chrisgrieser/cmp-nerdfont](https://github.com/chrisgrieser/cmp-nerdfont)**  
    Source de complétion pour les icônes NerdFont.
  - **[roobert/tailwindcss-colorizer-cmp.nvim](https://github.com/roobert/tailwindcss-colorizer-cmp.nvim)**  
    Prévisualisation des couleurs Tailwind CSS dans la complétion.
  - **[L3MON4D3/LuaSnip](https://github.com/L3MON4D3/LuaSnip)**  
    Moteur moderne de snippets.
    - **[rafamadriz/friendly-snippets](https://github.com/rafamadriz/friendly-snippets)**  
      Large collection de snippets prêts à l’emploi.
  - **[saadparwaiz1/cmp_luasnip](https://github.com/saadparwaiz1/cmp_luasnip)**  
    Intégration LuaSnip pour nvim-cmp.

---

### 🧠 LSP, Syntaxe & Outline

- **[nvim-treesitter/nvim-treesitter](https://github.com/nvim-treesitter/nvim-treesitter)**  
  Coloration syntaxique et parsing avancés.

  - **[JoosepAlviste/nvim-ts-context-commentstring](https://github.com/JoosepAlviste/nvim-ts-context-commentstring)**  
    Commentaires contextuels selon le langage.
  - **[windwp/nvim-autopairs](https://github.com/windwp/nvim-autopairs)**  
    Fermeture automatique des paires (parenthèses, guillemets, etc.).
  - **[hiphish/rainbow-delimiters.nvim](https://github.com/hiphish/rainbow-delimiters.nvim)**  
    Délimiteurs et parenthèses arc-en-ciel.

- **[nvim-treesitter/nvim-treesitter-context](https://github.com/nvim-treesitter/nvim-treesitter-context)**  
  Affiche le contexte courant du code en haut de la fenêtre.

- **[hedyhli/outline.nvim](https://github.com/hedyhli/outline.nvim)**  
  Affiche un plan/arbre du code pour une navigation facile.

---

### 📝 Édition & Productivité

- **[numToStr/Comment.nvim](https://github.com/numToStr/Comment.nvim)**  
  Commentaire de code rapide et simple.

- **[MeanderingProgrammer/render-markdown.nvim](https://github.com/MeanderingProgrammer/render-markdown.nvim)**  
  Rendu et prévisualisation Markdown dans Neovim.

- **[RRethy/nvim-align](https://github.com/RRethy/nvim-align)**  
  Alignement de texte pour le code et les tableaux.

---

### 📚 Documentation

- **[luckasRanarison/nvim-devdocs](https://github.com/luckasRanarison/nvim-devdocs)**  
  Accès hors-ligne à la documentation DevDocs directement dans Neovim.

---

### ⚡ Navigation

- **[ThePrimeagen/harpoon](https://github.com/ThePrimeagen/harpoon)**  
  Navigation rapide et favoris de fichiers.

---

### 🧹 Linting & Formatage

- **[mfussenegger/nvim-lint](https://github.com/mfussenegger/nvim-lint)**  
  Linting asynchrone pour de nombreux langages.

- **[stevearc/conform.nvim](https://github.com/stevearc/conform.nvim)**  
  Formateur de code rapide et extensible.

---

### 🧩 Intégration Git

- **[lewis6991/gitsigns.nvim](https://github.com/lewis6991/gitsigns.nvim)**  
  Indicateurs de modifications Git dans la colonne de signe.

- **[isakbm/gitgraph.nvim](https://github.com/isakbm/gitgraph.nvim)**  
  Visualisation de l’historique Git sous forme de graphe.

- **[f-person/git-blame.nvim](https://github.com/f-person/git-blame.nvim)**  
  Affiche les informations de blâme Git en ligne.

- **[sindrets/diffview.nvim](https://github.com/sindrets/diffview.nvim)**  
  Visualisation des diffs et de l’historique Git.

- **[SuperBo/fugit2.nvim](https://github.com/SuperBo/fugit2.nvim)**  
  Interface Git avancée pour Neovim.
  - **[chrisgrieser/nvim-tinygit](https://github.com/chrisgrieser/nvim-tinygit)**  
    Intégration légère de la CLI Git.

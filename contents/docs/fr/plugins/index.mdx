# 📦 Plugins utilisés

WhoaIDE s’appuie sur une sélection de plugins modernes pour offrir une expérience de développement complète et fluide.  
Voici la liste des principaux plugins, classés par catégorie.

---

### 🛠️ Gestion des plugins

- **[lazy.nvim](https://github.com/folke/lazy.nvim)**  
  Gestionnaire de plugins rapide et modulaire, utilisé pour charger et configurer tous les plugins de WhoaIDE.

---

### ✨ Interface & UI

- **[lualine.nvim](https://github.com/nvim-lualine/lualine.nvim)**  
  Barre de statut personnalisable et esthétique.
- **[tabby.nvim](https://github.com/nanozuki/tabby.nvim)**  
  Gestion avancée des onglets.
- **[nvim-web-devicons](https://github.com/nvim-tree/nvim-web-devicons)**  
  Icônes pour fichiers et plugins.
- **[dressing.nvim](https://github.com/stevearc/dressing.nvim)**  
  Améliore les fenêtres de sélection et d’entrée.
- **[nui.nvim](https://github.com/MunifTanjim/nui.nvim)**  
  Composants UI pour popups et menus personnalisés.
- **[snacks.nvim](https://github.com/folke/snacks.nvim)**  
  Dashboard et notifications stylées.
- **[noice.nvim](https://github.com/folke/noice.nvim)**  
  UI avancée pour les messages, commandes et notifications.
- **[indent-blankline.nvim](https://github.com/lukas-reineke/indent-blankline.nvim)**  
  Visualisation des indentations.
- **[nvim-colorizer.lua](https://github.com/NvChad/nvim-colorizer.lua)**  
  Affichage des couleurs dans le code.

### 🔍 Recherche & Navigation

- **[telescope.nvim](https://github.com/nvim-telescope/telescope.nvim)**  
  Fuzzy finder puissant pour fichiers, buffers, symboles, etc.
- **[telescope-symbols.nvim](https://github.com/nvim-telescope/telescope-symbols.nvim)**  
  Recherche de symboles et d’icônes.
- **[telescope-file-browser.nvim](https://github.com/nvim-telescope/telescope-file-browser.nvim)**  
  Navigateur de fichiers intégré à Telescope.
- **[telescope-node-modules.nvim](https://github.com/nvim-telescope/telescope-node-modules.nvim)**  
  Recherche dans les dépendances node_modules.
- **[telescope-software-licenses.nvim](https://github.com/chip/telescope-software-licenses.nvim)**  
  Recherche de licences logicielles.
- **[nerdy.nvim](https://github.com/2kabhishek/nerdy.nvim)**  
  Recherche et insertion d’icônes NerdFont.

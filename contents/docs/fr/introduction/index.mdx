# Bienvenue sur la documentation de WhoaIDE

🚀 **WhoaIDE** est une configuration Neovim moderne, rapide et prête à l’emploi, pensée pour les développeurs qui veulent un environnement de développement **puissant**, **minimaliste** et **esthétique**.

## ✨ Pourquoi utiliser WhoaIDE ?

- 🧠 **Pensée pour le flow** : des raccourcis clairs, une interface lisible, et une UX conçue pour t’aider à rester concentré.
- ⚡️ **Démarrage instantané** grâce à `lazy.nvim` et un setup optimisé.
- 🔌 **Plugins intégrés** : gestion des fichiers avec `neo-tree`, diagnostics avec `trouble.nvim`, LSP, autocomplétion, formatters, linters...
- 🎨 **Design cohérent** : une interface visuelle homogène grâce à des couleurs bien choisies et des composants unifiés.
- 🛠️ **Modularité** : chaque partie de la config est facilement éditable. Tu peux l’adapter à tes besoins (Typescript, Web, PHP, etc.)

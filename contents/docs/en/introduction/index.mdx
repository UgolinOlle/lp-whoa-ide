# Welcome to the WhoaIDE Documentation

🚀 **WhoaIDE** is a modern, fast, and ready-to-use Neovim configuration designed for developers who want a **powerful**, **minimalist**, and **aesthetic** development environment.

## ✨ Why use WhoaIDE?

- 🧠 **Flow-oriented**: clear shortcuts, a readable interface, and a UX designed to help you stay focused.
- ⚡️ **Instant startup** thanks to `lazy.nvim` and an optimized setup.
- 🔌 **Integrated plugins**: file management with `neo-tree`, diagnostics with `trouble.nvim`, LSP, autocompletion, formatters, linters...
- 🎨 **Consistent design**: a cohesive visual interface with carefully chosen colors and unified components.
- 🛠️ **Modularity**: every part of the config is easily editable. Adapt it to your needs (TypeScript, Web, PHP, etc.)

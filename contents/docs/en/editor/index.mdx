# 🛠️ Editing Plugins

The `lua/plugins/editor` folder contains plugins that enhance editing, navigation, productivity, and the Neovim interface in WhoaIDE.

---

## 📂 Navigation & File Explorer

- **[nvim-neo-tree/neo-tree.nvim](https://github.com/nvim-neo-tree/neo-tree.nvim)**  
  Modern file explorer with Git and buffer support, customizable and fast.

---

## 🔍 Search & Fuzzy Finder

- **[nvim-telescope/telescope.nvim](https://github.com/nvim-telescope/telescope.nvim)**  
  Powerful fuzzy finder for files, buffers, symbols, diagnostics, and more.  
  Included extensions:

  - [telescope-symbols.nvim](https://github.com/nvim-telescope/telescope-symbols.nvim) (symbols/icons)
  - [telescope-node-modules.nvim](https://github.com/nvim-telescope/telescope-node-modules.nvim) (npm dependencies)
  - [telescope-file-browser.nvim](https://github.com/nvim-telescope/telescope-file-browser.nvim) (file browser)
  - [telescope-software-licenses.nvim](https://github.com/chip/telescope-software-licenses.nvim) (licenses)
  - [nerdy.nvim](https://github.com/2kabhishek/nerdy.nvim) (NerdFont icons)

- **[MagicDuck/grug-far.nvim](https://github.com/MagicDuck/grug-far.nvim)**  
  Advanced find & replace with a modern interface.

---

## 🗂️ Tabs & Navigation Bar

- **[nanozuki/tabby.nvim](https://github.com/nanozuki/tabby.nvim)**  
  Advanced tab management with visual customization.

---

## 📝 Productivity & Tracking

- **[folke/todo-comments.nvim](https://github.com/folke/todo-comments.nvim)**  
  Highlights and navigates TODO, FIXME, and similar comments.

- **[Wansmer/symbol-usage.nvim](https://github.com/Wansmer/symbol-usage.nvim)**  
  Shows the number of usages, definitions, and implementations of the symbol under the cursor.

- **[wakatime/vim-wakatime](https://github.com/wakatime/vim-wakatime)**  
  Automatic coding time tracking (Wakatime statistics).

---

## 🖥️ Integrated Terminal

- **[akinsho/toggleterm.nvim](https://github.com/akinsho/toggleterm.nvim)**  
  Integrated and floating terminal in Neovim, with multi-terminal management.

---

## 🍫 UI & Dashboard

- **[folke/snacks.nvim](https://github.com/folke/snacks.nvim)**  
  Interactive dashboard, startup shortcuts, notifications, and Git/PR integration.

- **[Bekaboo/dropbar.nvim](https://github.com/Bekaboo/dropbar.nvim)**  
  Contextual navigation bar to help you locate yourself in the code structure.

- **[andweeb/presence.nvim](https://github.com/andweeb/presence.nvim)**  
  Discord Rich Presence integration (shows Neovim activity status on Discord).

---

> For more details on each plugin’s configuration, see the [`lua/plugins/editor/`](lua/plugins/editor/) folder.

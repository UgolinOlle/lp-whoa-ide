# 📦 Plugins used

WhoaIDE relies on a selection of modern plugins to provide a complete and smooth development experience.  
Here is a list of the main plugins, organized by category.

---

### 🛠️ Plugin Management

- **[lazy.nvim](https://github.com/folke/lazy.nvim)**  
  Fast and modular plugin manager, used to load and configure all plugins in WhoaIDE.

---

### ✨ Interface & UI

- **[lualine.nvim](https://github.com/nvim-lualine/lualine.nvim)**  
  Customizable and aesthetic statusline.
- **[tabby.nvim](https://github.com/nanozuki/tabby.nvim)**  
  Advanced tab management.
- **[nvim-web-devicons](https://github.com/nvim-tree/nvim-web-devicons)**  
  File and plugin icons.
- **[dressing.nvim](https://github.com/stevearc/dressing.nvim)**  
  Enhances selection and input dialogs.
- **[nui.nvim](https://github.com/MunifTanjim/nui.nvim)**  
  UI components for popups and custom menus.
- **[snacks.nvim](https://github.com/folke/snacks.nvim)**  
  Stylish dashboard and notifications.
- **[noice.nvim](https://github.com/folke/noice.nvim)**  
  Advanced UI for messages, commands, and notifications.
- **[indent-blankline.nvim](https://github.com/lukas-reineke/indent-blankline.nvim)**  
  Indentation visualization.
- **[nvim-colorizer.lua](https://github.com/NvChad/nvim-colorizer.lua)**  
  Displays colors in code.

---

### 🔍 Search & Navigation

- **[telescope.nvim](https://github.com/nvim-telescope/telescope.nvim)**  
  Powerful fuzzy finder for files, buffers, symbols, etc.
- **[telescope-symbols.nvim](https://github.com/nvim-telescope/telescope-symbols.nvim)**  
  Search for symbols and icons.
- **[telescope-file-browser.nvim](https://github.com/nvim-telescope/telescope-file-browser.nvim)**  
  File browser integrated with Telescope.
- **[telescope-node-modules.nvim](https://github.com/nvim-telescope/telescope-node-modules.nvim)**  
  Search in node_modules dependencies.
- **[telescope-software-licenses.nvim](https://github.com/chip/telescope-software-licenses.nvim)**  
  Search for software licenses.
- **[nerdy.nvim](https://github.com/2kabhishek/nerdy.nvim)**  
  Search and insert NerdFont icons.

---

### 🧠 LSP, Autocompletion & AI

- **[nvim-lspconfig](https://github.com/neovim/nvim-lspconfig)**  
  LSP server configuration.
- **[mason.nvim](https://github.com/williamboman/mason.nvim)**  
  Install and manage LSPs, linters, and formatters.
- **[mason-lspconfig.nvim](https://github.com/williamboman/mason-lspconfig.nvim)**  
  Mason + LSPConfig integration.
- **[mason-tool-installer.nvim](https://github.com/WhoIsSethDaniel/mason-tool-installer.nvim)**  
  Automatic tool installation.
- **[nvim-cmp](https://github.com/hrsh7th/nvim-cmp)**  
  Autocompletion engine.
- **[cmp-nvim-lsp](https://github.com/hrsh7th/cmp-nvim-lsp)**  
  LSP source for nvim-cmp.
- **[cmp-nerdfont](https://github.com/chrisgrieser/cmp-nerdfont)**  
  NerdFont icon completion.
- **[cmp_luasnip](https://github.com/saadparwaiz1/cmp_luasnip)**  
  Snippet completion.
- **[LuaSnip](https://github.com/L3MON4D3/LuaSnip)**  
  Modern snippet engine.
- **[friendly-snippets](https://github.com/rafamadriz/friendly-snippets)**  
  Collection of ready-to-use snippets.
- **[lsp_signature.nvim](https://github.com/ray-x/lsp_signature.nvim)**  
  Function signature display.
- **[fidget.nvim](https://github.com/j-hui/fidget.nvim)**  
  LSP status indicator.
- **[nvim-lsp-file-operations](https://github.com/antosha417/nvim-lsp-file-operations)**  
  File operations via LSP.
- **[avante.nvim](https://github.com/yetone/avante.nvim)**  
  AI integration (Copilot, Ollama, Claude, etc.).

- **[nvim-treesitter-context](https://github.com/nvim-treesitter/nvim-treesitter-context)**

- **[render-markdown.nvim](https://github.com/MeanderingProgrammer/render-markdown.nvim)**

- **[tabby.nvim](https://github.com/nanozuki/tabby.nvim)**  
  Advanced tab management.
- **[harpoon](https://github.com/ThePrimeagen/harpoon)**

  Dashboard and startup shortcuts.

### 🧹 Linting & Formatting

- **[nvim-lint](https://github.com/mfussenegger/nvim-lint)**  
  Asynchronous linting for many languages.
- **[conform.nvim](https://github.com/stevearc/conform.nvim)**  
  Automatic code formatting.

---

### 🧩 Git & Versioning

- **[gitsigns.nvim](https://github.com/lewis6991/gitsigns.nvim)**  
  Git change indicators in the gutter.
- **[gitgraph.nvim](https://github.com/isakbm/gitgraph.nvim)**  
  Git history visualization.
- **[fugit2.nvim](https://github.com/SuperBo/fugit2.nvim)**  
  Advanced Git interface.
- **[nvim-tinygit](https://github.com/chrisgrieser/nvim-tinygit)**  
  Git CLI tools.
- **[diffview.nvim](https://github.com/sindrets/diffview.nvim)**  
  Visual diff and Git history.
- **[git-blame.nvim](https://github.com/f-person/git-blame.nvim)**  
  Git blame display.

---

### 🧩 Miscellaneous

- **[zen-mode.nvim](https://github.com/folke/zen-mode.nvim)**  
  Zen mode for focused work.
- **[symbol-usage.nvim](https://github.com/Wansmer/symbol-usage.nvim)**  
  Shows symbol usage in code.

> **Note:**  
> Some plugins are configured to load only in certain contexts (lazy loading) to optimize Neovim performance.
